# TG Notification

Личный Telegram-бот с напоминаниями и Mini App для управления задачами.

## Возможности

- Создание задач в боте и в Telegram Mini App.
- Список задач с вкладками «Сегодня», «Завтра», «Все».
- Категории задач, дата и время напоминания.
- Кнопки «Начинаю», «Пока не могу», «Есть прогресс» и «Сделано».
- При «Пока не могу» бот уточняет причину и предлагает перенести на 10/30/60 минут, завтра в 09:00 или на своё время.
- Выбранное время переносится в самой задаче и в следующем напоминании.
- Три приоритета: высокий, средний и низкий, с сортировкой по срочности.
- Важные задачи требуют одного дополнительного подтверждения перед завершением, если прогресс ещё не отмечался.
- Утренний план из трёх главных дел и вечерний обзор с предложением переноса.
- Сохранение истории прогресса, переносов и причин; после нескольких переносов бот предлагает пересмотреть подход.
- Необязательный свободный диалог через OpenAI API, основанный на текущих задачах и последних действиях.
- Без реакции напоминания продолжаются до выполнения: высокий приоритет — каждые 10 минут (настраивается), средний — не чаще 30 минут, низкий — не чаще 120 минут. После «Начинаю» — контроль через 20 минут, после «Есть прогресс» — через 30 минут.
- Тихие часы по умолчанию с 23:00 до 08:00: повторные напоминания не отправляются. Утром просроченные уведомления возобновляются.
- Данные хранятся в SQLite.
- Доступ по Telegram ID только для владельца.
- Отдельный API с ключом для будущего подключения ChatGPT.

## Запуск

Нужен Node.js 22 или новее.

1. Скопируйте `.env.example` в `.env`.
2. Создайте бота в [@BotFather](https://t.me/BotFather) и задайте `BOT_TOKEN`.
3. Узнайте свой Telegram ID через [@userinfobot](https://t.me/userinfobot) и укажите `OWNER_TELEGRAM_ID`.
4. Выполните `npm install`, затем `npm start`.
5. Отправьте своему боту `/start`.

Для Mini App нужен публично доступный адрес **HTTPS**. Укажите `PUBLIC_URL=https://your-domain.example` и настройте у BotFather кнопку меню Mini App с URL `https://your-domain.example`. При наличии PUBLIC_URL бот также покажет кнопку открытия приложения.

При разработке на ПК сам бот может работать локально с long polling. Для Mini App потребуется HTTPS-туннель либо хостинг. Напоминания работают только пока процесс бота запущен.

## Переменные окружения

Смотрите `.env.example`. Не публикуйте токен Telegram или `INTEGRATION_API_KEY` и не коммитьте файл `.env`.

По умолчанию используется часовой пояс `Europe/Moscow`. Можно изменить через `TZ_NAME` (IANA). Утреннее сообщение в 09:00 (`MORNING_HOUR`), вечернее в 21:00 (`EVENING_HOUR`). Тихие часы: `QUIET_FROM_HOUR=23`, `QUIET_UNTIL_HOUR=8`.

Дайджесты автоматически отправляются один раз в соответствующий час, только если сервер в это время работает. Если сервер был выключен, пропущенный дайджест задним числом не отправляется. Для проверки вручную есть команды `/plan` и `/summary`.

### Режим личного секретаря (необязательно)

Впишите `OPENAI_API_KEY` в `.env` для свободного диалога в Telegram. Модель задаётся через `OPENAI_MODEL` (по умолчанию `gpt-4.1-mini`). Это **не** подписка ChatGPT Plus: OpenAI API оплачивается отдельно, по тарифам API. Без ключа создание задач, кнопки, приоритеты, напоминания, утренний план и вечерний обзор работают без нейросети.

При включении ИИ текст сообщений, активные задачи и недавние действия передаются через OpenAI API для формирования ответа. ИИ не может сам поменять задачу и не должен обещать, что что-либо сохранил. Запись и изменения выполняются только сервером по кнопкам. История беседы для ИИ временно хранится в памяти процесса и пропадает после перезапуска.

### Заметка о Mini App

Встроенное приложение поддерживает создание задач с приоритетом, список приоритетных дел, отметки старта и прогресса, выполнение, выбор приоритета и перенос на собственное время. Для запуска требуется HTTPS и открытие внутри Telegram. Время в интерфейсе Mini App отображается согласно часовому поясу устройства, а время в сообщениях бота — согласно `TZ_NAME`.

## Создание задачи в чате

Нажмите «➕ Создать задачку», затем пришлите название задачи, после чего выберите день и время. Можно создать задачу и без времени — без напоминаний.

## API для интеграции ChatGPT

В проекте предусмотрен защищённый API:

- `POST /api/integration/tasks` — создать задачу.
- `GET /api/integration/tasks` — получить задачи.

Авторизация: `Authorization: Bearer <INTEGRATION_API_KEY>`.

Тело POST:

```json
{
  "title": "Купить масло",
  "category": "Автомобиль",
  "priority": "high",
  "due_at": "2026-11-23T18:00:00+03:00"
}
```

`priority` принимает значения `high`, `medium` или `low` (по умолчанию `medium`). `due_at` можно не передавать, тогда задача создаётся без напоминания. Дата и время должны включать часовой пояс; API нормализует их в UTC.

Схема запросов для дальнейшего подключения находится в `openapi.yaml`. Чтобы команда в обычном чате ChatGPT действительно создавала задачу, нужно развернуть этот сервер по HTTPS, подключить API через собственный ChatGPT-плагин/совместимый коннектор и настроить его авторизацию. До этого интеграция является готовым серверным интерфейсом, а не подключённой функцией ChatGPT.

## Безопасность

Mini App проверяет подпись Telegram `initData` на сервере и Telegram ID владельца. На API интеграции используется отдельный ключ. Секреты и локальная SQLite-база игнорируются Git. Не размещайте базу данных на публичном сервере без контроля доступа и резервного копирования.

### Оговорки

Первый релиз рассчитан на одного пользователя и один запущенный экземпляр Node.js. Для круглосуточных напоминаний понадобится постоянно работающий хостинг или компьютер.
